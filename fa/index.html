پلتفرم‌های عملیاتی حوزه‌ی مخابرات، بانکداری و پرداخت را اداره می‌کنم و ۱۲ سال سابقه‌ی عملی در IT دارم که بیش از ۷ سال آن در DevOps بوده است؛ از Kubernetes روی سرورهای فیزیکی و CI/CD تا پایپ‌لاین‌های لاگی که بیش از ۱۰ ترابایت در ساعت داده دریافت می‌کنند.

وقتی مشکلی پیش می‌آید، می‌توانم آن را تا ریشه دنبال کنم: Kubernetes، لینوکس، سرورهای اپلیکیشن جاوا، Oracle و شبکه. در حال حاضر سرپرست تیم خدمات مالی موبایلی (MFS) در SAEI Group هستم.

  • ۲۰ میلیون+ کاربر
  • ۱۰ ترابایت لاگ در ساعت (اوج)
  • ۴۰٪ استقرار سریع‌تر
  • زیر ۱ هفته رفع کامل Log4Shell

سوابق کاری

ژوئن ۲۰۲۶ – اکنون

سرپرست تیم MFS · SAEI Groupفعلی

  • هدایت پشتیبانی روزانه‌ی محیط عملیاتی پلتفرم‌های خدمات مالی موبایلی و پرداخت، شامل مشکلات اپلیکیشن، پایگاه داده، زیرساخت و یکپارچه‌سازی.
  • هماهنگی انتشارها و تغییرات پرریسک با تیم‌های توسعه، پایگاه داده، زیرساخت و تأمین‌کنندگان؛ از بررسی‌های پیش از اجرا تا اجرا، اعتبارسنجی و پیگیری.
  • مسئولیت تحلیل ریشه‌ای (RCA) حوادث بحرانی مربوط به اپلیکیشن‌های جاوا، Oracle، یکپارچه‌سازی‌ها، شبکه و سرویس‌های وابسته.
  • مشارکت عملی در ارتقای پایگاه داده، مهاجرت محیط‌ها، خودکارسازی، مانیتورینگ و تغییرات پلتفرم.

Linux · Oracle · Java · Tomcat · WildFly · Kubernetes · GitLab CI/CD · Ansible · Bash · HAProxy · NGINX · Zabbix

اوت ۲۰۲۵ – ژوئن ۲۰۲۶

مهندس DevOps · AZMA Espadana

  • راه‌اندازی و نگهداری پلتفرم Kubernetes با ۵ نود control-plane مجازی و ۲۰ نود worker فیزیکی، به‌علاوه‌ی ۲ سرور رزرو برای ظرفیت و بازیابی.
  • راه‌اندازی Ceph با RBD، CephFS و S3 تا سرویس‌های stateful بتوانند از ذخیره‌سازی بلاکی، فایلی اشتراکی و آبجکت روی یک پلتفرم استفاده کنند.
  • استفاده از Kafka به‌عنوان لایه‌ی بافر و بازپخش برای پایپ‌لاین لاگی با اوج بیش از ۱۰ ترابایت در ساعت؛ جهش‌های بار جذب شد و از دست رفتن لاگ در معماری قبلی برطرف شد.
  • بهینه‌سازی Elasticsearch با لایه‌های hot/cold و ILM، و انتقال ظرفیت workerها از VMware vSphere به سرورهای فیزیکی برای کارایی و پایداری بیشتر.

Kubernetes · Cilium · Ceph · Kafka · Elasticsearch · Logstash · Zabbix · MongoDB

ژانویه ۲۰۲۴ – اوت ۲۰۲۵

مهندس DevOps · Asre Danesh

  • مهاجرت سرویس‌های عملیاتی از Docker Swarm به Kubernetes برای پلتفرم موبایل‌بانک با ۱۰ میلیون کاربر.
  • راهبری محیط‌های DR فعال/غیرفعال Kubernetes و ساده‌سازی منطق مشترک GitLab CI/CD که زمان استقرار را ۴۰٪ کاهش داد.
  • بازطراحی لاگینگ متمرکز با Fluentd DaemonSet و Elasticsearch برای پردازش بیش از ۱ ترابایت در روز، همراه با مدیریت بهتر نگهداشت داده با ILM و ایندکس‌ها.
  • جایگزینی NGINX Ingress با Kong، راه‌اندازی پشتیبان‌گیری Velero/MinIO و مهاجرت namespace برای DR، و سخت‌سازی لینوکس و Kubernetes برای قبولی در ممیزی امنیتی داخلی مطابق CIS.

Kubernetes · Docker Swarm · Helm · GitLab CI/CD · SonarQube · Fluentd · Elasticsearch · Kong · HAProxy · Velero · MinIO

اوت ۲۰۲۲ – ژانویه ۲۰۲۴

مهندس DevOps · Irancell Labs (ایرانسل)

  • مدیریت عملیات Kubernetes و استقرار عملیاتی «ایرانسل من» با بیش از ۲۰ میلیون کاربر روی کلاستر ۲۳ نودی (۳ نود control-plane و ۲۰ نود worker).
  • ساخت و نگهداری پایپ‌لاین‌های GitLab CI/CD، از جمله فرایند استقرار air-gapped از طریق Nexus Repository برای محیط‌های ایزوله.
  • استقرار WSO2 API Manager روی Kubernetes با Helm و پشتیبانی از ارتقاها، لاگینگ ELK، عیب‌یابی و حوادث آنکال.

Kubernetes · NGINX Ingress · GitLab CI/CD · Helm · Nexus Repository · WSO2 API Manager · ELK · Python

ژوئیه ۲۰۱۹ – اوت ۲۰۲۲

مهندس DevOps و پشتیبانی اپلیکیشن · 6D Technologies

  • در جریان Log4Shell، ابتدا با WAF سطح آسیب‌پذیری را کاهش دادم و سپس ارتقای Java و Tomcat را با Ansible خودکار کردم؛ اصلاح کامل در کمتر از یک هفته انجام شد.
  • خودکارسازی کارهای تکراری وصله، ارتقا و مهاجرت، یکسان‌سازی پیکربندی سرورهای اپلیکیشن و اعمال سخت‌سازی CIS روی Tomcat.
  • مهندس L3 محیط عملیاتی درگاه پرداخت: مدیریت Tomcat/WildFly، استقرارها، عیب‌یابی زیرساخت، هماهنگی با تیم پایگاه داده و رسیدگی به حوادث.

Linux · Ansible · Java · Tomcat · WildFly · Oracle · WAF
