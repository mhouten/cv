حدود ۱۲ سال است که در IT کار می‌کنم و بیش از ۷ سال آن در DevOps بوده. بیشتر روی زیرساخت سرویس‌های بزرگ مخابراتی، بانکی و پرداخت کار کرده‌ام؛ از کلاسترهای Kubernetes روی سرور فیزیکی و CI/CD گرفته تا سیستم لاگی که در اوج، ساعتی بیش از ۱۰ ترابایت لاگ می‌گرفت.

وقتی در پروداکشن مشکلی پیش می‌آید، از Kubernetes و لینوکس تا اپلیکیشن‌سرورهای جاوا، Oracle و شبکه دنبالش می‌روم تا به ریشه‌اش برسم. الان سرپرست تیم MFS (خدمات مالی موبایلی) در SAEI Group هستم.

  • ۲۰ میلیون+ کاربر
  • ۱۰ ترابایت لاگ در ساعت
  • ۴۰٪ دیپلوی سریع‌تر
  • زیر یک هفته رفع کامل Log4Shell

سوابق کاری

ژوئن ۲۰۲۶ – الان

سرپرست تیم MFS · SAEI Groupفعلی

  • مسئول پشتیبانی روزمره‌ی پروداکشن سرویس‌های مالی موبایلی و پرداخت هستم؛ از مشکلات اپلیکیشن و دیتابیس گرفته تا زیرساخت و ارتباط با سیستم‌های دیگر.
  • ریلیزها و تغییرات حساس را با تیم‌های توسعه، دیتابیس، زیرساخت و پیمانکارها هماهنگ می‌کنم؛ از چک‌های قبل از تغییر تا اجرا، تست و پیگیری بعدش.
  • RCA حادثه‌های جدی با من است؛ چه مشکل از اپلیکیشن جاوا باشد، چه از Oracle، شبکه یا سرویس‌های وابسته.
  • کنار مدیریت تیم، خودم هم دستی کار می‌کنم: آپگرید دیتابیس، مهاجرت محیط‌ها، اتوماسیون، مانیتورینگ و تغییرات پلتفرم.

Linux · Oracle · Java · Tomcat · WildFly · Kubernetes · GitLab CI/CD · Ansible · Bash · HAProxy · NGINX · Zabbix

اوت ۲۰۲۵ – ژوئن ۲۰۲۶

مهندس DevOps · AZMA Espadana

  • یک پلتفرم Kubernetes با ۵ نود control-plane روی VM و ۲۰ نود worker روی سرور فیزیکی راه انداختم و نگهداری کردم؛ ۲ سرور هم برای ظرفیت اضافه و ریکاوری کنار گذاشته بودیم.
  • Ceph را با RBD، CephFS و S3 راه انداختم تا سرویس‌های stateful از یک پلتفرم هم block storage داشته باشند، هم فایل مشترک و هم object storage.
  • برای سیستم لاگی که در اوج به بیش از ۱۰ ترابایت در ساعت می‌رسید، Kafka را به‌عنوان بافر و لایه‌ی replay گذاشتم. پیک‌ها جذب شد و مشکل گم‌شدن لاگ که در معماری قبلی داشتیم از بین رفت.
  • Elasticsearch را با hot/cold و ILM تیون کردم و workerها را از VMware vSphere به سرور فیزیکی بردم؛ هم سرعت بهتر شد، هم پایداری.

Kubernetes · Cilium · Ceph · Kafka · Elasticsearch · Logstash · Zabbix · MongoDB

ژانویه ۲۰۲۴ – اوت ۲۰۲۵

مهندس DevOps · Asre Danesh

  • سرویس‌های پروداکشن یک موبایل‌بانک با ۱۰ میلیون کاربر را از Docker Swarm به Kubernetes منتقل کردم.
  • محیط‌های DR (به‌صورت active/passive) روی Kubernetes را نگهداری کردم و منطق مشترک پایپ‌لاین‌های GitLab CI/CD را ساده کردم؛ نتیجه‌اش ۴۰٪ کاهش زمان دیپلوی بود.
  • لاگینگ متمرکز را با Fluentd و Elasticsearch از نو ساختم تا روزانه بیش از ۱ ترابایت لاگ را جواب بدهد، و نگهداری لاگ‌ها را با ILM و مدیریت درست ایندکس‌ها مرتب کردم.
  • NGINX Ingress را با Kong عوض کردم، بکاپ و انتقال namespace برای DR را با Velero و MinIO راه انداختم، و لینوکس و Kubernetes را طبق CIS هاردن کردم تا ممیزی امنیتی داخلی را پاس کنیم.

Kubernetes · Docker Swarm · Helm · GitLab CI/CD · SonarQube · Fluentd · Elasticsearch · Kong · HAProxy · Velero · MinIO

اوت ۲۰۲۲ – ژانویه ۲۰۲۴

مهندس DevOps · Irancell Labs (ایرانسل)

  • عملیات Kubernetes و دیپلوی پروداکشن «ایرانسل من» با بیش از ۲۰ میلیون کاربر روی یک کلاستر ۲۳ نودی (۳ control-plane و ۲۰ worker) با من بود.
  • پایپ‌لاین‌های GitLab CI/CD را ساختم و نگهداری کردم؛ برای محیط‌های بدون اینترنت هم یک روال دیپلوی air-gapped با Nexus Repository درست کردم.
  • WSO2 API Manager را با Helm روی Kubernetes دیپلوی کردم و آپگریدها، لاگینگ ELK، عیب‌یابی و آن‌کال آن را پشتیبانی می‌کردم.

Kubernetes · NGINX Ingress · GitLab CI/CD · Helm · Nexus Repository · WSO2 API Manager · ELK · Python

ژوئیه ۲۰۱۹ – اوت ۲۰۲۲

مهندس DevOps و پشتیبانی اپلیکیشن · 6D Technologies

  • در ماجرای Log4Shell، اول با WAF جلوی حمله را گرفتیم و بعد آپگرید Java و Tomcat را با Ansible و اسکریپت اتومات کردم؛ کل کار زیر یک هفته تمام شد.
  • کارهای تکراری مثل پچ، آپگرید و مهاجرت را اتومات کردم، کانفیگ اپلیکیشن‌سرورها را یکدست کردم و Tomcat را طبق CIS هاردن کردم.
  • مهندس L3 پروداکشن درگاه پرداخت بودم: مدیریت Tomcat و WildFly، دیپلوی، عیب‌یابی زیرساخت، هماهنگی با تیم دیتابیس و رسیدگی به حادثه‌ها.

Linux · Ansible · Java · Tomcat · WildFly · Oracle · WAF

مارس ۲۰۱۸ – آوریل ۲۰۱۹

ادمین لینوکس · SAEI Group (Echarge)
